foodcat - Figma Vector SVG UI Kit (11 Screens)
==============================================

How to import into Figma:
1. Open any Figma design file.
2. Drag and drop `00_All_Screens_Figma_Overview.svg` onto your Figma canvas to import all 11 screens side-by-side at once, OR drag individual screen files (`01_Splash_Screen.svg` through `11_User_Account_And_CatPro.svg`) into Figma.
3. All elements (cards, buttons, mascot vectors, icons, typography, and shadows) remain fully editable vector layers inside Figma.
